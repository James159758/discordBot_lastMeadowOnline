# 🌿 Last Meadow Online Automation Bot
### Auto Gathering • Crafting • Combat (Discord Game)

---

## ✨ Overview
This project is a **Discord automation script** for *Last Meadow Online* that handles:

- 🌾 Auto Gathering
- 🔨 Auto Crafting
- ⚔️ Auto Combat

It mimics user interaction with the game by sending requests directly to Discord endpoints.

---

## ⚠️ Disclaimer
> This is for **educational purposes only**. Automating Discord user accounts may violate Discord’s Terms of Service.

---

## ⚙️ Configuration

Before running, you must manually set:

- `Authorization` → Your Discord Authorization  
- `USER_AGENT` → Browser-like string  
- `X_SUPER_PROPERTIES` → Encoded Discord client properties  

---

## 📦 Requirements

Make sure you have the required dependency installed:

```bash
pip install aiohttp
```

This project uses **aiohttp** for asynchronous HTTP requests to interact with Discord efficiently.
